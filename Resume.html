RMIT - IOT project

GitHub Link:
context: (Team of 4) This was a technical project for an IOT development course, the task was to build 3 applications that would form a room booking system for study spaces in a building. This was implemented with local hosted flask apps on raspberry pi's, simulating phones room computers, and such.
tech: raspberryPi's, python, postgres, MQTT, Nix Flakes.
technical impact: I implemented a testing, deployment, and dev environment management system for the team using Nix flakes. outcome: this was a fun project, deploying each others work and testing the functionality was challenging and required a way of deploying and testing the 3 applications locally in way we could reproduce on a PI, some team members had challening personal circumstances and needed support during development aswell, however we recieved a high grade and gained valuable experience working in teams with Nix shells, MQTT, and postgres in a complex application.
