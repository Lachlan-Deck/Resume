RMIT - IoT project

GitHub Link
context: (Team of 4) This was a technical project for an IoT development course. The task was to build 3 applications that would form a room booking system for study spaces in a building. This was implemented with locally hosted Flask apps on Raspberry Pis, simulating phones, room computers, and such.
tech: Raspberry Pis, Python, Postgres, MQTT, Nix Flakes.
technical impact: I implemented a testing, deployment, and development environment management system for the team using Nix flakes. I built the booking system so that a client could view room availabilities in a web interface, make bookings, have their bookings confirmed and be sent a code for sign-in, sign into a room, and have the room's status change from vacant to occupied. This system was implemented across 3 different applications, using an MQTT server for which I wrote the listeners. I also implemented the Postgres database the "master"







would use to store the state of the system, using a Postgres trigger to manage booking updates across tables.
outcome: This was a fun project. Deploying each other's work and testing the functionality was challenging and required a way of deploying and testing the 3 applications locally in a way we could reproduce on a Pi. Some team members had challenging personal circumstances and needed support during development as well. However, we received a high grade and gained valuable experience working in teams with Nix shells, MQTT, and Postgres in a complex application.

RMIT – Final-year industry project

context: (Team of 4) This was an internal project for the RMIT course QA team. Its purpose was to scrape unformatted and changing information on a webpage and convert it into structured Excel documents.
tech: EC2, S3, Bedrock, Docker.
technical impact: I spiked and later implemented a change to the web-scraping architecture so that the LLM work had minimal token requirements, the outputs would be type-safe, and the pipeline could be tested separately. I also implemented a two-pass approach with a smaller, cheaper model that reduced our running costs and sped up the pipeline.
outcome: The clients were very happy with the work we did, and our team received a HD for the project work. My work reduced input tokens by ~66%, delivered a testing harness for the system, delivered type-safe LLM output with Pydantic and LangChain, and reduced costs by using cheaper models for non-reasoning LLM workloads.
